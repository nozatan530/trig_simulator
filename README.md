# 三角関数グラフシミュレータ

sin・cos・tan を関数ごとに独立したパラメータで操作。合成波・アニメーション対応の高校数学ツール。

🔗 **公開URL**: https://trig-simulator.meetupsensei.com/

## 概要

sin、cos、tan のグラフをそれぞれ振幅A・角周波数ω・位相φの3つのパラメータで自由に操作しながら、波形の変化をリアルタイムに観察できるシミュレータです。各関数の表示・非表示切替、最大値やゼロ点・不連続点のハイライト表示、sinとcosを足し合わせた合成波の表示にも対応しています。位相を自動的に変化させるアニメーション機能もあり、速度や対象の関数を選んで動きを確認できます。rad（ラジアン）/ deg（度数）モードの切替やライト/ダークテーマにも対応した、高校数学の三角関数学習に役立つツールです。

## 使い方

- 右側のスライダーで各関数（sin・cos・tan）の振幅A・角周波数ωを調整する
- 位相φは下部のチップ（-2π〜2πなど）をクリックして設定する
- 各関数名横の丸いボタンでグラフの表示・非表示を切り替える
- 「📍 特徴点ハイライト」ボタンで最大値・ゼロ点・不連続点をマーカー表示する
- 「➕ 合成波 (sin+cos)」ボタンで sin と cos を足し合わせた波形を表示する
- 「▶ 再生」ボタンでアニメーションを開始し、速度と対象関数を選択して位相の変化を観察する
- ヘッダーの rad / deg ボタンで角度の単位を切り替える
- ヘッダーの🌙ボタンでライト/ダークテーマを切り替える
- 「↺ 全パラメータをリセット」ボタンで設定を初期状態に戻す
